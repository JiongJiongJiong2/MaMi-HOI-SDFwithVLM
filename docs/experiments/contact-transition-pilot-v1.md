# CTP-01：完整接触转换的前瞻修正试验

日期：2026-09-22。状态：研究框架已确定，资产及数值配置待 T0 核验；不是已预登记的正式统计实验。用户要求准备本轮计划和实施提示词，本次文件任务没有运行实验。

入口：[研究状态](../../RESEARCH_START_HERE.md)。记录：[交接](../research/implementation-handoff.md)。本试验不重开 DWM P0/P0-R2、旧 MaMi residual 排序或 C0-R2。

## 问题与新信息

在同一粗运动、物体参考轨迹、姿态修正边界和计算预算下，提前使用接触过程信息是否能够改善接触建立、保持与释放，并由同一手—臂运动学链实现？先测实际收益空间，再决定是否存在值得学习的预测目标。

与已有试验的区别必须同时成立：使用连续事件而非孤立八帧门槛；修正进入可重建的人体/手参数而非仅平移网格；比较同预算的解析前瞻对照，最终按完整动作评价。若这三个差异无法落地，停止在资产结论，不包装为新 WM 实验。

物体轨迹先固定，只研究运动学修正。几何贴合不等于承重或物理稳定。不优化物体响应、不做主动触觉、不引入大模型训练。上肢缺失时可描述一个独立手部诊断，但不能默认为本协议等价实现。

## T0：资产和任务契约

目标是核对并冻结最小输入，不创建大型数据工程。只读检查现有数据与实现，可运行必要的有界元数据/几何检查；不新下载数据、不训练、不启动全量 manifest。如果已授权服务器可用，先确认没有同名任务和输出再使用；记录实时状态而非沿用历史日志。

优先复用 MaMi 全身输出、E5 的几何/求解工具及已存在的原始几何。EPIC B 正在处理的资产只有在已完整写出且来源清楚时可只读复用；不复制启动它的任务。必须验证人、手、物体是否属于同一序列，不能把 EPIC 的手和 MaMi 的身体拼成监督真值。

最多选 12 个开发片段作为初步试验，选择依据只允许数据完整性、事件覆盖、对象/序列身份及固定排序；不能按新方法是否获益选片段。优先覆盖多个对象和失败类型。这个上限是计算约束，不是统计充分性的保证。连续片段需覆盖完整开始、保持、释放及两侧非接触背景；不插值跨越数据缺口伪造完整事件。

交付 `docs/experiments/ctp01-t0-asset-contract.md` 与对应小型机器可读清单，至少记录：

- 源路径、来源版本/哈希、序列/对象/参与者、帧率和单位、开发数据使用历史；原始手/人体参数、对象网格与变换分别在哪里。
- 同一人体模型的腕部 attachment、左右手顺序、FK/蒙皮路径、MANO 与主体参数关系；哪个函数能真正执行手腕/手指/手臂修正。
- 接触阶段来源和质量：人工核验、参考标签或距离规则；规则标签不得标为物理真值。生成动作与参考阶段的时间映射必须明确。
- 完整片段数、缺失字段、排除原因、可视化样例以及所有重复/相关序列归组。
- smoke 和 T2 使用的确切时间范围、候选修正界限、求解步数、候选数量、种子、时间/显存上限、主要指标与守护指标容许变化、统计聚类单位。

数值配置只能依据原基线配置、训练侧尺度或测量误差确定，并在查看组间效果前保存。不能先跑出结果再补门槛。尚缺的数据、指标定义或上肢接口必须写成阻塞项，不能用默认值冒充已核验。

T0 分别给出：几何数据就绪、完整事件就绪、手—臂映射就绪、评价与预算就绪。全部就绪才进入 T1；缺项则交付可复现缺口及最小补齐建议。有效的不可行诊断也是 T0 完成。

## T1：可执行修正接口和 smoke

前置：T0 契约已落盘，映射可核对。先选清单中固定的两个片段，不扩大样本。

实现最小执行接口：同一输入状态加有界候选修正，输出合法人体/手参数及由 FK/蒙皮重建的网格。允许手腕目标、低维手指参数和支撑手臂补偿，但不能一并引入新的全身生成器。所有方法共享执行器和姿态边界。

必须验证零修正能够重建原输入；检查单位/坐标、骨长和连接关系、关节界限、物体固定、非目标部位变化。包含一项已知方向的小修正检查，防止“代码运行了但动作未生效”。重建误差容许值在 T0 基于精度确定；不能对含多种误差的任意数据直接照搬 MANO 的 1e-6 门槛。

复用 E5 时先重现其相应局部行为，再标清共同接口下的变体；E5 原版固定腕和物体，不与多自由度方法混作同预算机制对照。保存 before/after 参数、网格指标和完整视图，验证不能仅靠单帧最近点。

交付 `docs/experiments/ctp01-t1-executor-smoke.md`、聚焦代码/测试和小型汇总；大网格与视频只记录路径。未通过就停止在实现问题，不启动 T2、训练或全面重构。

## T2：无学习的下游收益与上限诊断

前置：T1 有效且 T0 数值契约已冻结。用清单中其余/全部约定开发片段，按冻结规则报告；调过参的片段显式标为校准样本，不能混为未见验证。不得使用 E5 保留 test 或把已查看的 EPIC/OakInk test 重标成新的盲测。

| 组 | 作用与输入 | 比较意义 |
|---|---|---|
| U：不修正 | 原始同一输入 | 测量问题规模 |
| R：反应式几何 | 当前几何、相同任务条件与历史；同一执行器 | 诊断逐时刻修正的限制 |
| G：解析前瞻几何 | 相同参考未来轨迹与 H 时域；接触/平滑目标 | 主要强对照，不能故意让它只看当前帧 |
| O：阶段信息上限 | G 的输入与执行预算，加核验过的预期接触阶段来调度约束 | oracle 诊断，额外标签明确披露，不能称部署公平胜出 |

各组共享初始状态、修正边界、约定算力或求解预算、随机性和评价。报告真实耗时；不能只同迭代数但不报告单次成本。H 根据真实帧率写为时间，不能在不同数据集间混用“8 帧”。R 与 G 用于时域诊断；任何未来学习模块都必须主要与 G 比，不能只报 R。

这是离线粗运动修正，可以读取任务允许的参考未来；不得称为在线传感预测。若另做在线版本，只使用当时可获得的信息，并单独声明。O 的标签可能不可在线获得，所以只回答未来阶段信息的价值上限。

在共同候选池下可加离线最优候选选择，作为本池诊断上限：使用同一评价端点，不把它当模型输入。它是用评价选最优的乐观上界，不是独立泛化成功；手段不能仅回到旧 78 事件池。没有较好候选时，优先定位执行器/动作空间，不训练更强排序器。

### 指标与验证

主要终点由 T0 冻结为阶段分解的接触误差：预期接触期的手表面贴合、预期释放/非接触期的错误吸附分别报告，禁止只奖励全程靠近。同时报告接触建立/释放时间误差和预期保持阶段的相对漂移；任务允许的滑动要单独标记，不能全算失败。

守护指标至少包含独立几何检查、关节合法性、腕连接、运动加速度/jerk和非目标身体偏移。对不支持可靠符号的网格不输出“真实穿透深度”；报告可用的无符号距离及局限。优化内部评分不能是唯一最终证据，至少使用独立实现/更精确表面评价与完整序列可视化核对。

主比较 O-G、辅助 G-R；逐序列配对，相关片段按原序列聚类；seed、帧和候选不充当独立样本。报告原始效应、序列数量、改善/恶化分布、区间和失败例。小样本区间不稳定时标为证据不足，不强做统计晋级。重要改善幅度和守护指标容许变化在 T0 冻结，不事后制定统一百分比。

交付 `docs/experiments/ctp01-t2-outcome.md`、逐序列小型结果、配置/数据身份与可复算命令，附代表性成功和失败片段。保留所有有效样本，披露缺失与失败，不因效果差删除。

## T3：结果解释与是否学习的决策

T3 默认是独立证据复核与新协议建议，不训练。

| 现象 | 合理下一步 |
|---|---|
| 候选上限也无实际收益 | 动作空间或执行接口缺少解决能力；不新增排序网络 |
| G 已经很好，O 没有增量 | 当前任务未说明阶段预测需求；保留几何结果 |
| O 对 G 有实质收益但片段很少 | 扩充独立开发证据的方案，不立即宣布创新或开正式训练 |
| O 增益稳定且动作/守护指标良好 | 定义预测所缺信息、可获得监督和强基线，再提出学习协议 |
| 只预测误差变小、最终动作无改善 | 不升级为 WM 成功；检查评分到执行的连接 |

若后续预测只调度接触阶段，称为接触预测模块即可。若研究动作条件 WM，明确哪些后果没有被 action 指定，数据来自什么执行系统。全部未来几何已给定时，用精确计算；学习代理必须证明成本/质量优势。物理响应主张不能用运动学优化产物替代验证。
