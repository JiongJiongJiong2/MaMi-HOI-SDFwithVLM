## MaMi Processed Data

The local MaMi processed sequence file contains 602 sequences with:

```text

```

It does not contain:

```text

```

Therefore, the current MaMi cache cannot supervise finger-level contact
memory or handover. The existing E3-D projection results remain derived
geometry, not raw finger supervision.

## EPIC-Contact and HOPformer

The official HOPformer repository was audited at commit:

```text
bcb114776419ec044634e8587bfb6381d6c45b63
```

The repository is available, but the actual EPIC-Contact and ARCTIC data
directories are not present. The README describes EPIC-Contact as:

```text
2.3K clips / 62.3K frames
gated access
CC BY-NC 4.0
```

The public code references contact fields including `dist.or`, `dist.ro`,
`idx.or`, and `idx.ro`, plus left/right validity and object geometry.
These are promising B-level fields, but the local audit cannot verify:

- sequence boundaries and clip duration;
- release or transition annotations;
- bimanual handover definitions;
- exact object and hand coordinate conventions;
- whether the two hands exchange control of the same object.

The vocabulary of the code is not a substitute for inspecting the gated
files.

## Interpretation

B is blocked by missing local complete event data. ARCTIC raw data or
EPIC-Contact could plausibly unblock it after access and schema
verification.

C remains more strongly blocked. Even if EPIC-Contact is obtained, it
must first demonstrate comparable initial/final object pose with a
different later hand role or explicit handover. A dataset with bimanual
hands is not automatically a handover dataset.
