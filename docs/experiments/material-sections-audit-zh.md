# 材料边界截面定量检查（2026-09-09）

后续局部检查已完成：三个双线中点均能沿向下路径无碰撞到达现有 mesh 包围盒外，不能把双线间距认定为实体壁厚。详见[盒口局部连通中文报告](plasticbox-rim-connectivity-zh.md)。文末原“下一步”已执行，无需重复。

**结论：截面线可以辅助方案 A。plasticbox 盒口部分双线确实来自不同位置的表面，不能全部归因于重复面；但本轮没有恢复完整可信的材料内外定义。优先方案 A 不变，没有切换方案 B，没有生成新 SDF，也没有解除训练 Gate。**

此前“缺材料边界”应准确理解为“尚未验证一套完整、一致的材料边界”，不能理解为“mesh 没有任何有效表面，或任何地方都没有第二层表面”。另一方面，图中有闭合轮廓也不自动意味着其中都是材料：桶腔可以是闭合水平轮廓包围的空气。

## 实际做了什么

新脚本 `scripts/audit_material_sections.py` 读取 plasticbox、trashcan、smalltable 的 canonical PLY。每个对象检查 10 个截面：x/y 包围盒中面，以及 z 高度比例 0.15、0.5、0.85、0.895、0.9、0.905、0.95、0.99。z 比例是包围盒高度的比例，不是以米计的坐标。重点比较原图 z=0.12984 m 附近的三个 plasticbox 切片。

逐三角面求交，保存每条线及扫描线交点的原始 face ID。仅在诊断图中合并距离小于 `1e-8 × max_extent` 的端点、合并同端点线段，并用 `1e-6 × max_extent` 重查主要拓扑计数。没有移动 mesh 顶点、补洞、封口、添加厚度或导出修复 mesh。共面三角形显式记录为特殊情况；本次 30 个切片的共面三角形计数均为零。

原始线图中的“简单闭合环”只指整个连接分量每个点都恰好连接两条边。主环带毛刺会不满足这个条件，所以额外做了**悬挂线段递归剥离**：只移除诊断图中不属于任何环的叶边，不连接断点。这能恢复带小毛刺的主环，但不能当作三维 mesh 修复。分叉图内部仍可能含环，不能因为简单环计数为零就宣称所有轮廓都不闭合。

## 三个对象的结果

| 对象与切片 | 合并的重复线段 | 原始断端 / 分叉点 | 诊断图剥离后的情况 | 能支持的判断 |
|---|---:|---:|---|---|
| plasticbox，中部 z 比例 0.5 | 479 | 2 / 41 | 仍有 40 个分叉点，没有独立无分叉大环 | 主轮廓有大量重叠/分支，不能直接按轮廓填充材料 |
| plasticbox，盒口附近 z 比例 0.9 | 446 | 8 / 49 | 仍有 44 个分叉点 | 部分双表面真实存在，但全截面内外环未恢复 |
| trashcan，中部 z 比例 0.5 | 1 | 1 / 1 | 删除 1 条悬挂边后恢复 1 个闭合主环 | 轮廓可恢复，但不是表达壁厚的内外双环 |
| trashcan，z 比例 0.9 | 4 | 3 / 3 | 删除 3 条悬挂边后恢复 1 个闭合主环 | 同样没有得到材料环带 |
| smalltable，全部 10 个切片 | 0 | 均为 0 / 0 | 简单闭合环，不需剥离 | 与桌面、桌腿的截面结构一致；不是全局几何证书 |

上述 plasticbox 重复线组均可找到方向相反的原始面法向。因此重复面污染确实存在，但这与下述“分离的双线”是两种不同情况。plasticbox 在 z 比例 0.895 处找到的两个独立小环面积仅为 4.28 和 12.68 mm²，不是包围盒体的内外两大环。

trashcan 中部沿 x/y 中心扫描线分别只得到两个不同位置的交点，即左右两侧各一个；不能把两侧间约 187 mm / 267 mm 的桶腔跨度当成壁厚。它仍可帮助确定几何外形和腔体位置，但不提供已知材料内部的正例。

因此，这一处双线不是同位置反向面画了两遍。两处不同表面在相邻切片中持续出现，具备继续审阅的局部几何线索。每个交点内部仍可能有反向重复面，不能直接使用任意一个原始法向作为可靠内外方向。

**这些间距不是已经测定的材料厚度。** 它们沿 x 方向测量，不是两片表面的法向最短距离；盒口可能有翻边、折返或空气间隙。三个切片之间持续出现双表面，也不等于它们之间已经被证明是实体塑料，更不能外推为整面盒壁和盒底都具有该厚度。当前不把这些区域从 unknown 强行改成 material。

## 验证与边界

五项解析测试 PASS：实心盒单环、有明确壁厚的开口杯双环且顶部无盖、反向重复面不伪造厚度、共面/断线不强行补全、带悬挂线的闭环可在诊断图中恢复。解析杯中部得到 `[-1, -0.8, 0.8, 1]` 四个交点，能区分两侧 0.2 壁厚与中间 1.6 腔体跨度。

本地最终三对象执行 13.20 秒，峰值进程 working set 114.36 MiB。三份 PLY 与脚本/辅助代码共五个绑定文件 hash 前后相同。`git diff --check` 通过。结果只来自本地 CPU，本轮未在 AutoDL 重跑。

当前方法不完整处理重叠边分裂、相切、所有平面图面域或三维自相交。容差对照也不是任意尺度的稳健性证明。因此这些结果既不能宣布 A 已通过，也不能证明所有有限处理都无法修复。诊断图里剥离了边，并不代表 mesh 的材料语义已改变或被验证。

## 对方案 A 的影响与唯一下一步

本轮收窄了问题：plasticbox 可以从已追踪的右侧盒口双表面入手；trashcan 的单环可辅助外形/腔体判断，但未给出材料厚度。**下一步仅对 plasticbox 已列出的右侧盒口面组做三维局部连通与折返检查，沿邻接三角面追踪，判断两片表面是可围出材料的两侧，还是翻边包围的空气/开放片。** 保留 unknown，不指定人工厚度，不修改源 mesh，不用这一局部结果直接重建全对象 SDF。

这仍属于 A 的几何证据调查。原 source-sign / penetration evaluator blocker、CUDA smoke BLOCKED 和 U1 20k BLOCKED 均保持；BPS 对照和 unsigned 梯度检查不需要重跑。

  --data_root_folder /root/autodl-tmp/mamihoi/data/processed_data \
  --output_dir /root/autodl-tmp/mamihoi/outputs/sdf_gate0/stage_a/material_sections_v1
